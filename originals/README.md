# Оригиналы фото

Необработанные фото Николая Петровича Ерохина, какими их прислали в чат — без
поворота, обрезки и выравнивания перспективы. Для сайта эти же фото
сжаты, выровнены и обрезаны в `public/images/gallery/` и `public/images/portrait/`.

Эта папка не используется сайтом (не внутри `public/`) — она только
для семейного архива, чтобы исходники не потерялись.

Если название файла не совпадает один в один с подписью на сайте — смотрите
по году и сюжету: сайт показывает тот же снимок, просто обрезанный и
выровненный под карточку.
