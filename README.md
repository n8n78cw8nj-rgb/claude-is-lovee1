# Наследие — страницы памяти

Одностраничное приложение (SPA) для создания и показа мемориальных страниц: загрузка фото, видео, аудио и «оживлённых» портретов, QR-карточки и таблички для печати, экспорт и импорт в ZIP. Работает без сервера: все данные хранятся в браузере.

Встроенная страница-пример — **Ерохин Николай Петрович (1939 — 2000)**: она часть сайта, её видит любой посетитель, на неё ведёт QR. Как её наполнять — в разделе [«Страница Ерохина Н. П.»](#страница-ерохина-н-п).

## Запуск

```bash
git clone https://github.com/n8n78cw8nj-rgb/claude-is-lovee1.git nasledie
cd nasledie
npm install
npm run dev          # http://localhost:5173
```

Сборка:

| Команда | Результат |
|---|---|
| `npm run build` | `dist/` для хостинга (Vercel, Netlify, любой статический). Включает service worker: после первого открытия сайт работает офлайн. |
| `npm run build:artifact` | `dist/artifact.html` — версия для просмотрщика Claude Artifacts. |
| `npm run build:file` | `dist/index.html` — **один файл** (~4 МБ), открывается двойным кликом без сервера. |
| `npm run preview` | Локальный просмотр собранного `dist/`. |

> Обычный `dist/index.html` после `npm run build` нельзя открыть двойным кликом: браузеры блокируют модули с `file://`. Для этого используйте `npm run build:file`.

## Страница Ерохина Н. П.

Прямая ссылка: `<адрес сайта>/#/m/erokhin` — сразу открывает страницу памяти (её же кодирует QR). Посетитель по такой ссылке видит только страницу: без меню сайта, кнопок редактора, списка, QR-студии и ZIP; работать со страницей — с главной, «Мои страницы». На главной она в списке «Мои страницы памяти», её имя, годы и портрет (в медальоне) — на 3D-памятнике.

**Тексты** — `src/data/memorial.json`: ФИО, даты, место рождения, эпитафия (строки стиха через `\n`), биография (абзацы через пустую строку `\n\n`), хронология, слова близких, символ на QR-табличке и памятнике (`cross` — крест, `star` — звезда, `none` — без символа).

**Фото, видео, аудио** — файлы в `public/`, пути заданы в том же `memorial.json`:

| Файл | Где на странице |
|---|---|
| `public/images/portrait/portrait.jpg` | Портрет в шапке. Пока файла нет — круг с инициалами. |
| `public/images/gallery/01_1939_детство.jpg` … | Галерея по годам с подписями; те же фото — у абзацев биографии и у событий хронологии (см. ниже). |
| `public/videos/animated-portrait.mp4` | «Ожившее фото»: запускается само, без звука, по кругу. |
| `public/videos/animated-2.mp4` | Блок «Видео». |
| `public/audio/biography.mp3` | Кнопка «Послушать историю жизни» играет запись вместо синтеза речи браузера. |

Сайт проверяет файлы при сборке: чего нет — того нет и на странице, вместо битых картинок — заглушки. Положили файл → `npm run build` (на Vercel — просто пуш в ветку) → он на странице; в `npm run dev` страница обновится сама. Фото — до 2 МБ, длинная сторона до 2560 px; видео — MP4 (H.264).

Правки этой страницы в редакторе браузера живут только в этом браузере и сбрасываются, как только на сайте меняется её содержимое; постоянные изменения — в `memorial.json`. Кнопка «Удалить» на её карточке отменяет такие правки, саму страницу удалить нельзя.

### Фотографии: годы, подписи, привязка

Каждое фото описано в `memorial.json`:

- `gallery` — по порядку лет: `{"file": "01_1939_детство.jpg", "year": "1939", "caption": "1939 год. Детство"}`. Имя файла — `NN_ГГГГ_описание.jpg`. Известно только десятилетие — `"year": "1950-е"` и `NN_1950е_описание.jpg`, фото стоит рядом с 1950 годом; год примерный — `"year": "около 1969"` и `NN_около-1969_описание.jpg`. Год неизвестен — `XX_примерно-1960е_описание.jpg`, фото в конце галереи.
- `biography` — абзацы: `{"text": "…", "photos": ["01_1939_детство.jpg"]}`. Фото стоит справа от абзаца (на телефоне — над ним), с подписью; два и больше — рядом.
- `timeline` — у события `"photo": "01_1939_детство.jpg"` или список имён: миниатюры под событием.

Клик по любому фото открывает его крупно, с подписью; листаются все фото страницы. В сетке и у абзацев показываются миниатюры из `thumbs/`: миниатюру можно заменить своей, например с лицом крупнее, — `sync` её не перезаписывает. Фото, которые положили в папку без записи в `memorial.json`, тоже видны — в конце галереи, без подписи.

Обработка — `scripts/photos.mjs` (нужен ImageMagick):

| Команда | Что делает |
|---|---|
| `node scripts/photos.mjs import <файл> 1960_астория.jpg` | Кладёт фото в `public/images/gallery/`: до 2560 px и 2 МБ, поворот по EXIF, без метаданных (в том числе GPS), миниатюра 800 px в `thumbs/`. |
| `node scripts/photos.mjs portrait <файл>` | Портрет: `public/images/portrait/portrait.jpg`. |
| `node scripts/photos.mjs sync` | Сортирует галерею по годам, переименовывает файлы в `NN_ГГГГ_…` (без года — `XX_…`, в конце), обновляет ссылки абзацев и событий и миниатюры. |
| `node scripts/photos.mjs report` | Отчёт: какое фото где стоит, что не привязано, у каких фото нет года или указан не точный год, а десятилетие или период. |

**Ожившее фото.** `public/videos/animated-portrait.mp4` сделан из портрета 1957 года без внешних сервисов: он моргает и чуть покачивает головой, 8 секунд по кругу. Повторить или сделать из другого фото — `python3 scripts/animate_photo.py <фото> public/videos/animated-portrait.mp4` (нужны ffmpeg и `pip install mediapipe==0.10.14 opencv-python-headless scipy`). Ролик из HeyGen, Kling или D-ID кладётся на это же место, в MP4 (H.264).

**Озвучка.** `public/audio/biography-text.txt` — текст биографии для [Yandex SpeechKit Playground](https://aistudio.yandex.ru/docs/ru/speechkit/operations/tts-playground.html) (≈2500 символов, лимит — 5000): голос **filipp**, скорость **0.9**, формат **MP3**. Готовый файл — в `public/audio/biography.mp3`.

## Возможности

- **Hero** с 3D-памятником (Three.js / React Three Fiber): гранитная стела с портретом в медальоне и QR-табличкой, вращение 0,01 рад/кадр, наклон при наведении, тёплый свет, золотые пылинки.
- **Список страниц**: поиск, сортировка, счётчики фото/видео/оживления, просмотр, редактор, QR, удаление, дублирование, экспорт одной страницы в ZIP. Кнопка «Загрузить 10 примеров» создаёт демо-страницы (военный, учительница, врач, сталевар, швея, лётчик, поэтесса, агроном, музыкант, инженер).
- **Редактор**: портрет, ФИО, даты, места, эпитафия (200 символов), биография, хронология, галерея (до 500 фото), видео (до 50), оживление (MP4 из Kling / D-ID / HeyGen), аудио, слова близких, контакты (с переключателем видимости). Drag-and-drop, прогресс, превью в реальном времени, Ctrl+S.
- **Медиа**: JPG, PNG, WEBP, GIF, HEIC (конвертация в JPEG), TIFF (декодирование UTIF), до 50 МБ; фото сжимаются до 2560 px, миниатюры создаются автоматически. Видео MP4, MOV, AVI, MKV, WEBM до 2 ГБ хранятся без перекодирования. Если формат не проигрывается браузером (например, AVI), файл сохраняется и доступен для скачивания.
- **Озвучка биографии** на русском: кнопка «Послушать историю жизни» читает имя, даты, эпитафию, биографию и хронологию встроенным синтезатором речи браузера (без сервера и платных сервисов). Пауза, перемотка по фразам, скорость, выбор голоса, подсветка читаемого абзаца. Если у страницы есть готовая запись (MP3), кнопка играет её. Работает и в экспортированной странице из ZIP.
- **Просмотр** в том виде, в каком его увидит посетитель: портрет, ожившее фото с автозапуском, биография, хронология, галерея с лайтбоксом и зумом, видео, аудио, цитаты, контакты, QR.
- **QR-студия**: визитка 85,6 × 54 мм, табличка A6 105 × 148 мм, наклейка 70 × 70 мм. Светлое и тёмное оформление. Печать в размер изделия или раскладкой на A4 с линиями реза. PDF (~300 dpi), QR в PNG и SVG. Уровень коррекции **H**.
- **Настройки**: статистика и заполненность хранилища, экспорт и импорт всех данных в ZIP (восстановить или добавить копиями), экспорт одной страницы, базовый адрес для QR, очистка неиспользуемых файлов, «Очистить всё».

## Деплой на Vercel

https://vercel.com/new → Import этого репозитория → Deploy. Настройки сборки берутся из `vercel.json`.

## Хранение

| Данные | Где |
|---|---|
| Тексты и метаданные | LocalStorage (`nasledie:memorials`) |
| Фото, видео, аудио, миниатюры | IndexedDB (`nasledie` → `media`) |
| QR-коды | генерируются на лету |

Приложение просит браузер сделать хранилище постоянным (`navigator.storage.persist`). При переполнении появляется сообщение с предложением экспортировать данные в ZIP.

### Формат ZIP

```
data.json        — { format: "nasledie-export", version, memorials[], media[] }
media/<id>.<ext> — исходные файлы
thumbs/<id>.webp — миниатюры
index.html       — (только для экспорта одной страницы) готовая статичная страница памяти
qr.png           — (только для экспорта одной страницы)
```

Экспорт одной страницы можно сразу загрузить на любой хостинг: `index.html` открывается без приложения.

## QR-ссылки

По умолчанию QR ведёт на `https://наследие.рф/m/<id>` (в punycode). Изменить домен можно в **Настройках → Адрес QR-кодов**. Кнопка «Применить ко всем страницам» пересчитывает ссылки всех страниц. Ссылку отдельной страницы можно поменять в QR-студии.

QR встроенной страницы всегда ведёт на тот сайт, с которого она открыта: `<адрес сайта>/#/m/erokhin` — её данные есть у любого посетителя. При сборке на Vercel рядом кладётся `images/qr.png` (1024 px, уровень H) для гравировщика — с production-доменом проекта. На другом хостинге адрес задаётся так: `SITE_URL=https://example.ru npm run build`.
